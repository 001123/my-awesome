## Running models & chat UIs

- [ollama/ollama](https://github.com/ollama/ollama) — Run open-source LLMs (Qwen, DeepSeek, Gemma, gpt-oss...) on your own machine with a single command. ⭐ 185k · Go · _added 2026-10-25_
- [open-webui/open-webui](https://github.com/open-webui/open-webui) — Self-hosted ChatGPT-style chat UI for Ollama or OpenAI-compatible APIs, with RAG and MCP. ⭐ 157k · Python · _added 2026-10-25_
- [janhq/jan](https://github.com/janhq/jan) — Desktop ChatGPT alternative that runs 100% offline. ⭐ 45k · Rust · _added 2026-10-25_
- [Mintplex-Labs/anything-llm](https://github.com/Mintplex-Labs/anything-llm) — Local-first AI platform: chat with your documents, agents, RAG. ⭐ 68k · JavaScript · _added 2026-10-25_

## Inference, gateways & fine-tuning

- [vllm-project/vllm](https://github.com/vllm-project/vllm) — High-throughput, memory-efficient LLM serving engine, the industry standard for production. ⭐ 95k · Python · _added 2026-10-25_
- [BerriAI/litellm](https://github.com/BerriAI/litellm) — Gateway to 100+ LLM APIs in the OpenAI format, with cost tracking and load balancing. ⭐ 62k · Python · _added 2026-10-25_
- [unslothai/unsloth](https://github.com/unslothai/unsloth) — Fine-tune and run LLMs faster with less VRAM, now with a local UI. ⭐ 79k · Python · _added 2026-10-25_
- [hiyouga/LlamaFactory](https://github.com/hiyouga/LlamaFactory) — Fine-tune 100+ LLMs/VLMs with LoRA, QLoRA and RLHF through one unified interface. ⭐ 76k · Python · _added 2026-10-25_
- [huggingface/transformers](https://github.com/huggingface/transformers) — The standard library for using and training text, vision and audio models. ⭐ 168k · Python · _added 2026-10-25_
- [deepseek-ai/DeepInfer](https://github.com/deepseek-ai/DeepInfer) — DeepSeek's official high-performance inference framework for serving DeepSeek models at large scale. ⭐ 22k · Python · _added 2026-10-26_
